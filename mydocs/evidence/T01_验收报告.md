## 3. 实机发现与修正

首个普通 profile 原型发现 `ModHooks.LoadedModsWithVersions` 在启动完成时为空，无法代表当前加载列表。对 Modding API v77 源码核对后，Runtime 改为在 `FinishedLoadingModsHook` 内调用：

```csharp
ModHooks.GetAllMods(onlyEnabled: true, allowLoadError: false)
```

verification preflight 与 manifest 复用同一份名称/版本快照。修正后普通 profile 稳定识别 15 个启用 Mod。
