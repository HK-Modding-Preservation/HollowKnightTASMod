# Task Spec T18: 普通用户使用文档

- **Status**: READY_FOR_IMPLEMENTATION
- **Gate**: G6 Product Completion
- **Depends On**: T04, T06, T09, T11, T12, T15
- **Produces**: `docs/用户使用指南.md`、README 快速入口、命令与界面核验记录

## 1. Goal

让未参与开发、不了解内部协议的普通 Hollow Knight Mod 使用者，能够仅按文档
完成安装、首次启动、录制/回放、手动与定时存档、存档恢复、外部 Companion
使用、常见故障恢复和安全卸载。

## 2. Required Content

- 支持的游戏/API/平台版本和发布包结构。
- 安装、升级、卸载和用户数据位置。
- 默认设置、游戏内菜单项、需要重启才生效的设置。
- 所有实际可用快捷键及其上下文。
- 创建/校验/运行 `.hktas` 的最短工作流。
- F5 手动存档、F8 列表、自动存档、保留策略、专用槽覆盖确认和恢复暂停点。
- Companion 自动启动、只读/Approved Control 的区别。
- 面向高级用户的 CLI、SDK、MCP 文档链接，但不要求普通用户先学 API。
- 常见问题：Companion 未启动、manifest 不匹配、回放 desync、专用槽冲突、
  紧急停止、日志/证据位置。
- 明确安全边界：Replay Save 不是完整进程快照；调试 mutation 会使当前进程
  失去验证资格。

## 3. Verification

- 文档中的每个文件名、菜单项、默认值、快捷键和 CLI 命令必须与当前源码或
  `--help` 输出逐项核对。
- 在干净临时目录按文档执行离线 movie format/validate 示例。
- README 首页提供可发现的“普通用户快速开始”链接。
- 不把尚未实现的 Studio 操作、热键或能力写成已交付功能。

## 4. PASS

- 新用户可以从发布包安装后完成一次最小回放和一次 Replay Save 恢复。
- 自动存档与外部接口的开启方式、风险和恢复方式没有歧义。
- 所有示例命令可复制执行，链接有效，术语与产品界面一致。

## 5. FAIL

- 只有架构/开发文档，没有用户步骤。
- 文档要求手改私有协议、猜路径或使用未实现 UI。
- 快捷键、默认槽位、菜单名、命令参数与代码不一致。

## 6. Rollback

文档不改变运行时状态；若某项产品能力尚未通过，只能标注限制或删除该步骤，
不得以文档承诺替代实现。
