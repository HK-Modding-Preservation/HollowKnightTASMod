# D08 时间线世界线树

用户要求直接实现：初始 Frame 0，每次全流程存档新增节点，修改历史自动产生分叉；叶子表示世界线，按世界线选择祖先节点恢复；删除节点及其子树。

空白会话修正：Studio 新打开且 Movie 为空时默认显示仅含 Frame 0 的未存档起点；旧存档导入的时间线保留于下拉列表，需主动选择。旧版快捷槽不出现在空白序列的时间线快捷槽中。

实现约定：
- 边界 Frame N 表示输入 [0,N) 已执行。按已执行输入、FPS、输入模式及环境的 canonical 前缀匹配，选帧号最大的兼容节点作父节点，同帧选最新节点。未来草稿不参与父节点匹配。重复保存仍产生独立节点，编号不复用。
- 每个新建／打开并预置的全流程 Movie 有独立时间线，旧树保留在下拉列表。浏览另一棵树不改变运行中的游戏，成功恢复才切换当前编写时间线。
- 叶子选择世界线，选其祖先确定恢复位置；用叶子 Movie 恢复到祖先 Frame，因此保留该世界线的后续序列。
- 恢复采用现有受保护冷启动重放，不是内存快照；沿用原始存档哈希及环境校验。单击图节点只选择，恢复按钮才改变游戏。
- 右键保存、时间线当前帧保存、全流程快捷槽均新增节点。右键读档按所选世界线定位同帧节点，避免同帧不同分支覆盖。v1 旧存档路径不变。
- 删除弹窗显示子树规模，不可撤销；删除起点时清空后代并保留 Frame 0 锚点。删除不改变当前游戏或草稿。快捷槽引用随子树删除失效。
- 本地 studio-frame-saves/timelines.json 原子替换持久化；单次写失败不发布内存修改，加载异常保留原文件。旧 index.json 能引用到的存档一次性导入，旧文件保留。旧版本已覆盖而不在索引中的历史不猜测恢复。
- 深色可滚动树图，所选路径绿色连线，所选节点粗边框，右侧显示世界线路径与保存时间。没有存档时只显示起点。

验证需覆盖用户两种等价工作流、同帧不同输入／FPS 分叉、未来修改不改变过去归属、子树删除和兄弟保留、重开持久化、恢复祖先时保留所选叶子的未来输入，以及安装版 UI smoke。
