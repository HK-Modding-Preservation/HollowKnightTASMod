# 回档显示冻结

用户要求：沿用冷启动重放，但回档期间游戏画面保持原样；Studio 帧序列不跟随、不刷新中间帧，可暂时禁止操作。恢复完成后一次显示目标结果。

## 当前实现范围

- v2 Studio 的过去帧恢复、Timeline 世界线恢复、快捷槽，以及共用 `RestartDraftAtAsync` 的重放接续入口。
- Companion 在退出源进程前通过 Windows Graphics Capture 截取窗口表面并显示独立遮罩；被 Studio 遮挡时仍捕获游戏自身。截取失败时不退出原进程。遮罩沿用源窗口位置和层叠顺序，不抢焦点。
- 新游戏经已验证 Injector 隐藏启动；ClockBridge 仅在回档环境标志存在时拦截 UnityPlayer 的窗口创建、显示、层叠、激活及样式写入，阻止 Unity 再次显示启动白屏。原生启动门闩确认后由 Companion 将窗口放在遮罩后方，继续正常绘制与重放。完成后设置窗口属性解除拦截，正常启动不安装这些钩子。
- 系统音频会话暂时静音，结束时还原会话原静音状态。达到精确 Movie 帧、原生帧已暂停后，捕获目标画面、等待 DWM 合成再撤掉遮罩；不为刷新显示推进模拟帧。
- 表格保留原对象、当前标记、选区、列头与滚动位置；后台状态仍继续接收。顶部帧计数同样冻结。
- 恢复进度条以 Runtime 上报的已完成 Movie 帧数 / 本次目标帧数填充，不显示数字、不使用循环动效。重启准备阶段为空条，只有新回放 ArmReplay 后才接收进度；目标为零时等待准备完成，不除以零。核心恢复成功后填满，原有显示解除流程不变。
- 完成后重建目标序列及标记。自动跟随开启时跳到目标；关闭时恢复滚动偏移。勾选状态不变，普通播放仍正常跟随。
- 失败时释放遮罩、音频与交互冻结并显示错误。旧进程一旦退出，不承诺失败时还能返回旧游戏状态。

## 验证边界

定向测试覆盖跟随开启/关闭、后台中间帧、世界线 Movie 替换、最终标记与选区、Windows 音频接口。安装版需验证真实窗口截取、进程替换、目标帧精确暂停、失败收尾和原始存档不变。独占全屏、跨 DPI 显示器及显示模式切换不能继承窗口模式验证结果。旧版 v1 恢复监督器尚未接入此显示层。
