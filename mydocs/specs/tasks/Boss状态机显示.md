# Boss 状态机显示

Studio 的“Boss 状态机”页支持选择场景对象，将各个 PlayMaker FSM 分别画成可缩放、平移和折叠的图，并高亮采样帧的当前状态。选择对象后可添加本体和子对象的 FSM；独立场景控制器可手动勾选。原始状态名、事件名和对象路径保留，实例标识用于区分同名对象。

## 数据与同步

- 复用 `getWorldSnapshot` 的原生帧边界只读通道，新增 `view=fsmCatalog` 和 `view=fsms`。目录按需分页，页面打开时约每 3 秒刷新；选中项每 100 ms 单请求采样一次，最多 32 个 FSM。
- `fsmCatalog` 返回对象、祖先 ID、场景和 FSM 实例 ID。`fsms` 的 `watches` 是 JSON 字符串数组，每项为 `id|knownStructureHash`；返回同一帧的状态及发生变化的图结构。所有读取都在 Unity 主线程安全边界完成。
- 图结构包含起始状态、状态节点、普通和全局转移、已加载动作的类型。仅读取现有 backing fields，不调用 PlayMaker 初始化 getter。每张图上限 512 个状态、4096 条转移；超限明确报错。
- 运行时采样可能略过中间状态；不推断真实转移事件。暂停查询不推进帧，单步后下一次采样刷新。结构变化才重新布局。
- 场景切换、断线和重建期间取消有效高亮，异步结果以会话和请求代次隔离。冷重建只重新绑定场景、路径及 FSM 名称均唯一的目标；同名歧义要求重新选择。
- 普通游戏启动不启用此功能；离开页面后停止请求。纯 C# 状态机需另行适配。

## 验收

1. 定向检查覆盖循环、全局转移、未加载动作、同名实例、子对象选择、数量上限和过期高亮。
2. 真实 WPF 渲染检查多图、当前节点、禁用状态、缩放与定位。
3. 安装版游戏验证 Boss 多 FSM、暂停重复采样、单步、连续运行、冷重建和跨场景失效；比较关闭和打开查询的同输入结果。
4. 保护原始存档、用户配置和时间线；保留测试证据。每个完成阶段本地提交，远端推送不在本次范围内。
