# D12 步进与全局热键

## 用户要求

1. 操作「逐帧」改为「步进」（英文 Step）。
2. 按住步进快捷键连续步进，松开停止。
3. 提供设置选项，游戏窗口获得焦点时仍可使用热键。

## 实现

- 设置页新增「启用全局热键」，默认关闭，立即保存到 %LOCALAPPDATA%/HollowKnightTAS/studio-global-hotkeys.txt。原快捷键文件兼容，不迁移或改写。
- 全局范围：配置的播放/暂停及步进键、F1–F10 恢复、Shift+F1–F10 保存。Ctrl+O/S 和表格编辑快捷键保持 Studio 内使用。
- 全局启用时，通过 Win32 RegisterHotKey（MOD_NOREPEAT）注册，命令回到同一 ViewModel 路径；不激活或前置 Studio，不切换时间线页面。
- Studio 自身及其原生对话框获得前台时释放全局注册，由原本 WPF 快捷键处理，保留输入框保护。切换到其他进程后重新注册。冲突按键在设置页列出，其他注册成功的键仍可用；下一次离开 Studio 会重试。
- Studio 内长按采用键盘重复事件，仅允许步进重复。全局长按通过 40ms 定时器观察物理按键状态，首次 350ms 延迟后重复；松开、修饰键改变、关闭选项、进入 Studio 或关闭窗口即停止。
- 所有重复都检查原 StepCommand.CanExecute；AsyncRelayCommand 已防重入。没有补发队列，慢帧结束后不会集中执行历史重复请求。已经提交的一帧不因松键而中断。
- 关闭窗口开始保存时先停止全局监听；保存失败留窗后恢复设置。正式退出释放注册和定时器。
