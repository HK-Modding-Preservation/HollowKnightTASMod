# D13 保存节点不定位

## 行为

保存第 X 帧只记录完整序列、原始存档基准和恢复目标，不调用播放、步进、重启或重放。运行中仍先暂停以获取一致的记录。当前帧保存和快捷槽存档共用此路径。

保存使用当前输入草稿；录制时合并已录制输入与草稿未来帧，不修改正在运行的游戏或当前草稿。原生第 0 帧的快照本身就是草稿，因此不会重复拼接未来输入。

TimelineNode 新增可选 IsUnverified 标记（旧节点默认 false）。目标超出已观察进度，或输入前缀与实际运行不符，显示未验证存档。未验证节点不作为 MatchingSavedFrame 的执行证据，也不作为实际最远叶子的父节点；保存目标不会提高最远进度。对应输入真正运行到目标后，UpdateTip 可确认节点并挂入已执行路径。未来书签单独显示为可恢复叶子，实际最远进度叶子仍保留。
