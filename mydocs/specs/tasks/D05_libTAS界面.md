# D05：面向 libTAS 使用者的 Studio

## 目标

让熟悉 libTAS 的使用者按原有习惯找到启动、播放/暂停、逐帧、输入编辑、存读档与视频导出。改动以 Companion 为主，复用人工和 AI 共用命令，不修改原生游戏输入、存档算法或冻结的 Runtime/Core 安装身份。

参考官方 [MainWindow](https://github.com/clementgallet/libTAS/blob/master/src/program/ui/MainWindow.cpp)、[KeyMapping](https://github.com/clementgallet/libTAS/blob/master/src/program/KeyMapping.cpp)、[Input Editor](https://clementgallet.github.io/libTAS/guides/options/)。只参考布局和行为，自行实现 WPF 代码。

## 分阶段任务

1. 主窗口：File / Settings / Movie / Tools / Input 菜单，常驻 Start、Play/Pause、Frame Advance、帧号与运行状态，诊断信息退出主要创作区域。接入 Pause、V、Ctrl+O/S；文本编辑时不吞掉字母输入，不因键盘自动重复连发操作。验证编译、命令映射、文本焦点和窗口布局后单独提交。
2. Input Editor：以帧为行、按键为列，当前帧与选区可辨；单击切换、范围编辑、插入/删除、复制/粘贴、撤销/重做及定位。编辑过去输入必须通过已有分支重建路径，不能只改画面表格或直接修改游戏。保留文本脚本入口。用小序列验证编辑结果与实际提交内容一致。
3. 存档与操作习惯：10 个 TAS 快捷槽，Shift+F1…F10 保存、F1…F10 恢复，显示槽对应帧号和兼容性；保留完整存档管理与覆盖授权。补快捷键设置及焦点规则，评估 Tab 快进的真实支持，不能将普通继续运行改名为快进。回档期间明确显示重放进度和取消。小范围验证保存、恢复、空槽和重复按键。
4. 集成与交付：把常用操作与高级诊断分层，完善中文迁移说明；验证最小窗口和常用缩放、菜单/键盘/鼠标一致、保存回档及 MP4 入口不回退。只更新签名 Companion，保留 Runtime/Core 哈希，安装后做一次短 smoke，更新包并提交。

## 行为边界

- 单步、播放、保存和恢复必须展示真实状态；未连接、等待中和失败不可显示为成功。
- 快捷键使用同一命令服务；焦点不在 Studio 的游戏快捷键行为需明确验证和说明，不能默认把窗口内快捷键称为全局支持。
- 文本、表格和运行中 movie 的关系必须明确；本地编辑不意味着已经回放，恢复不会静默丢弃编辑。
- HK 固定时钟、基于输入重放的回档、兼容校验、原版存档覆盖授权不为模仿 UI 而绕过。
- 小改定向检查，相关改动汇总后一次 smoke；每完成一阶段提交，不重跑旧战斗矩阵。
