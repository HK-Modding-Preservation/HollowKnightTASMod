# Studio 交互体验

用户要求规划后直接执行。范围覆盖全流程 v2；旧 v1 保留既有编辑路径。

1. 第 0 帧没有选择 Movie 时，播放/逐帧自动新建录制。
2. 输入列表采用压缩 run 索引和有界行缓存；WPF 回收可视行，滚动覆盖整段 Movie，末尾滚动按块补空帧。
3. 右键帧菜单提供选区编辑、存档、已有存档恢复、播放到指定边界暂停。回放定位必须由帧边界控制，不能依赖 UI 定时轮询。
4. 鼠标按下锁定输入列及目标开关状态，纵向拖拽确定连续范围，释放时一次修改并形成一个撤销步骤；允许横向离开原列。
5. 默认行高 19，保留可辨认的帧号和当前帧标记。
6. 默认 FPS 用于新补空帧；选区 FPS 写入序列并影响实际游戏步长。缺省值保持旧 Movie 的时间语义及 canonical identity，切片/复制/粘贴/撤销保留 FPS。
7. 顶部菜单、子菜单、右键菜单、分隔线共用深色模板。

验证：定向测试覆盖长序列随机访问、区间编辑与边缘、帧率 roundtrip/切片、空 Movie 启动、精确边界；最终构建与 UI smoke。实机证据单独记录，不将编译通过等同游戏行为通过。
