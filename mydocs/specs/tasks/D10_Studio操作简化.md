# Studio 操作简化与分支持续保存

本轮按用户 14 项反馈调整，保留从游戏 Modding 菜单进入 Studio 的现有逻辑，仅去掉顶部 Start 按钮。

## 操作与显示

- 顶部移除 Stop；Movie Text 页面移除，文件打开和保存、MP4 入口放在 Input Editor。
- 撤销、重做、复制、粘贴、插入、删除独占第一行。第二行保留文件操作、默认帧率弹框、重新计算到选中帧、跟随和 MP4。
- 移除刷新、分页箭头、Frame/Count 输入、定位/当前帧、应用分支、选区动作下拉/切换按钮、模拟轴按钮及常驻 FPS 输入框。使用表格直接选择；右键修改选区帧率。
- 剩余标签页直接可见，去掉按菜单打开/收起工具页的机制。MP4 取消仍可在序列菜单操作。
- 回档保留静止图像与表格，同时显示不带数字的等待进度条。

## 执行与文件切换

- 重新计算使用独立 rebuild 路径，允许目标在当前、过去或未来，不再错误调用仅允许未来帧的 seek。
- 打开文件先验证，暂停现有会话、保存分支后替换草稿；仅 Unarmed 的第 0 帧立即预置，其余标记待重启，播放时从起点恢复。禁止录制同步覆盖刚打开的文件。
- Runtime 每约 200 ms 主动发布状态，播放期间无需等待暂停快照或 UI 轮询才收到进度；回档仍抑制表格跟随。

## Timeline 叶子

用户明确要求叶子为该分支实际运行到的最远帧，非草稿长度。叶子保存完整 Movie，手动存档保持独立且不被覆盖。回到祖先不降低原叶子最远帧；修改已执行前缀产生另一条分支，不能把尚未执行的修改标成已运行。

- 暂停、切换文件/世界线、关闭 Studio 时持久化最远进度。旧节点和快捷槽保持兼容。
- 点击叶子切换完整序列；重放/恢复沿用既有受保护路径。切换前保存原分支。
- 关闭时保存失败则保持窗口并报告错误；不会静默丢弃草稿。保存到 Timeline 不等同于覆盖用户导出的 .hktas 文件。
- 数据原子写入，最远进度叶子可变，显式存档不可变。新增存档可以成为既有叶子的父节点，叶子 ID 保持稳定；验证树无循环。

## 本轮验证

定向覆盖最远帧不回退、未来草稿保存、过去编辑分叉、短序列不覆盖旧叶子、显式节点重挂接和重载、快捷槽、运行时跟随与恢复冻结。安装版需验证新界面、帧率弹框、实时跟随、重算当前帧、中途换文件恢复、关闭重开后分支持久化。证据统一记录在 artifacts/studio-simplification/REPORT.md。
