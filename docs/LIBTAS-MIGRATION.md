# 从 libTAS 迁移到 Studio

Studio 保留 libTAS 使用者熟悉的入口，但底层仍遵守 Hollow Knight TAS 的固定时钟、兼容校验和输入重放规则。

## 常用入口

- `File 文件`：启动游戏、退出 Studio。
- `Settings 设置`：打开 `Hotkeys 快捷键`、Runtime 控制和自动存档设置。
- `Movie 序列`：打开或保存 Movie，进入 `Input Editor 输入编辑器`、`Movie Text 文本脚本` 和 `Savestates 存档管理`。
- `Tools 工具`：打开高级编排、状态检查、事件日志和其他诊断面板。
- `Encode to MP4 导出视频`：从 `Movie 序列` 菜单或 Movie 页面进入 MP4 导出。

主窗口常驻 `Play / Pause`、`Frame Advance`、帧号和运行状态。菜单与按钮使用同一控制命令。

## 快捷键和焦点

默认播放/暂停是 `Pause`，逐帧是 `V`；可在 `Settings → Hotkeys` 中分别改为可用按键并保存。`Ctrl+O` 打开 Movie、`Ctrl+S` 保存 Movie，固定不改。

快捷槽固定为：

- `F1`–`F10`：恢复对应槽位；
- `Shift+F1`–`Shift+F10`：保存到对应槽位。

这些快捷键只在 Studio 窗口获得焦点时生效。文本框和组合框获得焦点时，字母、空格等输入优先留给编辑控件；按键自动重复不会重复提交。打开轴编辑等 Studio 子窗口时，主窗口快捷键会暂时停用。

## 输入编辑

`Input Editor` 以帧为行、按键为列，支持单击切换、Shift 连续选区、插入、删除、复制/粘贴和撤销/重做。模拟轴可编辑 `-10000` 到 `10000`；轴与方向键冲突时会拒绝修改。

表格改动先写入 Movie 草稿，不会自动改变游戏状态。使用 `应用分支` 提交草稿；需要把游戏重放到目标帧时，使用 `应用并重放到 Frame`。完整生命周期序列仍使用 `Advanced Authoring`。

## 存档语义

快捷槽只保存存档引用、帧号和待确认标签，不是瞬时内存快照。恢复由现有 Broker 执行兼容性检查、覆盖授权和输入重放；保存中的旧引用会保留到新存档达到 `Ready`。完整存档管理和原版覆盖授权继续保留。

当前没有真正的加速播放命令；`Tab` 仍是窗口焦点导航，不代表快进。

## 验证边界

新版 Companion 已签名安装；Shift+F1 保存与 F1 跨启动恢复到第 326 帧已实测，界面显示恢复阶段和完成状态。中文输入法下的文本焦点保护、点击表格后 V 单步，以及表格修改提交到 Runtime 已实测。模拟轴弹窗输入、改键、分支回退与真实窗口缩放仍在验证；尚未更新最终交付包。
