# 键盘逐帧输入

在 Studio「设置」开启「键盘逐帧输入」。在游戏窗口操作时，还需开启「全局热键」。该输入模式每次打开 Studio 默认关闭。

游戏进入可输入状态并同步键位后，按住游戏按键，再按逐帧快捷键（默认 V）：

- 上为 W、攻击为 J 时，按住 W＋J，点按 V：下一帧填写上＋攻击并执行。
- 跳跃为 K 时，按住 K＋V：每次步进都填写跳跃；松开 K 继续按 V，后续帧填写松开状态。
- 松开 V 停止连续步进。进行中的一次步进会完成；忙碌期间的重复请求不会积压。

每次快捷键步进会覆盖下一帧的键盘动作，未按住的动作写为松开。已经执行的前缀保持不变，未来输入保留为可编辑意图。FPS、RNG 种子和其他输入数据保留。通过原有草稿撤销入口可撤销填写；撤销已执行帧后，需要按既有流程重放。

鼠标点击顶部「步进」仍执行表格原有输入，不采集键盘。关闭此模式后，快捷键也恢复执行表格。文本输入框和 Studio 对话框继续保护文字输入。

键位取自当前游戏的原始键盘绑定，不使用固定 WASD 模板，不把手柄绑定当键盘键。等待键位同步、发现逐帧键与游戏键冲突、遇到不支持的键名时，会显示原因并停止此次步进。修饰键作为游戏键时，现有不带修饰键的 Studio 热键可能不触发；当前验证范围为 W／J／K 等普通键。

验证说明：单元测试覆盖组合键、连续采样、释放、绑定错误和 Movie 前缀／元数据。实机联调使用注入的按键状态经过真实游戏绑定、Studio 写帧和 Runtime 执行；不等同于物理键盘与游戏焦点的完整验收。
