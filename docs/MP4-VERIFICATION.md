对原始 MP4 解码后，以 50 fps 逐帧接触表观察画面，以 480 样本（10 ms）窗口计算音频 RMS。接触表按从左到右、从上到下排列。以下为画面事件与附近音频变化的人工对应，不是分离音轨后的音效识别，也不是听感测试。

| --- | --- | --- |
| Studio 300 帧短片 | 5.36 秒出现挥砍刀光 | 5.33–5.34 秒响度上升，5.38 秒局部峰值为 -16.83 dB |

证据位于 `artifacts/d04-live/`：`studio-attack-sheet.png` 从 5.10 秒开始；`full-early-sync.png` 从 5.20 秒开始；`full-impact-sync.png` 从 32.42 秒开始；`full-late-sync.png` 从 60.00 秒开始。相邻画面间隔 20 ms，音频数据为 `studio-rms.txt` 和 `full-rms.txt`。

抽样的画面事件与音频变化相邻，未发现随视频长度增长而出现的明显错位。0 / 32 / 65 秒附近的音频 packet 相对视频锚点分别相差 0 / 0 / 2.667 ms。背景音乐和其他音效会影响 RMS，因此这些结果不支持逐音效的精确延迟保证，也不代表主观听感评价。

## 功能与失败边界

| 要求 | 验证依据 |
| --- | --- |
| 已写序列自动导出 | 完整假骑士视频；Studio 按钮导出 `studio-300.mp4`，300 帧、音画各 6 秒、Completed |
| 暂停不延长视频，继续执行余下输入 | `sequence-pause-180.mp4`：第 6 帧暂停，两次查询均为 6 帧；继续后总计 180 帧，音画各 3.6 秒 |
| 游戏声音按模拟时间输出 | UnityFrameCapture 使用 AudioRenderer；AudioBlockReframer 保留 DSP 块余量；整数和分数帧率、样本连续性测试 |
| 取消、已有目标文件保护 | 实机取消无输出文件；编码器定向测试覆盖连接前取消及编码中目标文件被创建，不覆盖目标 |
| 有界传输与清理 | 音画各两个缓冲区，阻塞时背压；临时文件完成后才发布；编码器退出测试验证失败与清理 |
| 人工和 AI 共用接口 | Studio、SDK、MCP 都调用 Broker 的 StartVideoExport / CancelVideoExport；Runtime 校验权限和 operationId |
| 正常回放语义 | 导出通过既有 StartReplay / Step；采集在完整帧边界，不写角色、Boss 或 TAS 时钟状态；活动期间拒绝换序列及回档 |
| 用户交付 | 配套 Mod、序列、portable save、MP4、导入与启动脚本、START-HERE 和 SHA256SUMS |

在本机 Windows x64、游戏 1.5.78.11833、800×450 / 50 fps 环境验证。其他机器、所有分辨率和声卡未穷尽测试；导出要求保持分辨率和声音格式稳定。文件冲突与编码器退出采用定向测试，未为验证磁盘满而填满用户磁盘。
