# HollowKnightTAS Studio 操作手册

Studio 用来在《空洞骑士》中逐帧播放、编辑和回退 TAS 输入。普通启动游戏不会激活 TAS 功能。需要使用时，在标题界面的 `选项 → Modding → HollowKnightTAS` 点击 `打开 Studio（重启游戏）`，游戏会重新启动并停在第 0 帧；如果先打开 Studio，也可以点击 `Start 启动` 拉起受控游戏。

## 开始前

`Native frame: 0` 表示游戏的第一个原生 PlayerLoop 尚未执行。全流程 v2 Movie 在此时通过 `Movie → New full-run Movie 从第 0 帧新建` 或 `Movie → Open Movie 打开…` 预置；没有选择 Movie 时直接逐帧或播放，会自动新建空序列并开始录制。游戏加载期间的原生循环不消耗 Movie 帧；Movie 第 0 帧是第一个可接受真实游戏输入的循环。`Frame Advance` 会穿过加载，直到完成一个 Movie 帧才停下。

新建前可在 `Settings → Enable game mouse for new v2 Movie 启用游戏鼠标` 设置游戏鼠标；默认关闭，标题菜单仍可用键盘操作。打开已有 v2 Movie 时使用文件记录的鼠标模式。开始后模式固定，Studio 自身的鼠标不受影响。

手动点击后，Studio 先校验启动组件，再让标题进程退出并启动受控游戏。局内不能执行此操作，请先正常保存退出到标题。启动失败会保留原游戏，可从同一按钮重试；移交期间离开标题会取消本次请求。每次普通启动都需要重新点击，即使 Studio 已在后台运行，也不会自动接管普通游戏。未点击时不启用 TAS 的输入记录、时钟控制、检查器、快捷键、叠加层或存档重定向，普通游玩仍使用原始存档。

v2 会话中的标题菜单、选槽、局内操作以及 Save&Load 都走真实游戏输入。游戏对原始存档只读；保存、删档和建档作用于受保护影子副本，不自动写回原件。打开 Movie 前请确保所用槽位存档由你自己对齐。原生门闩和 Runtime 会在启动过程中接管，无须手动预选存档。

顶部四个控件是最常用的运行控制：

- `Play / Pause`：继续或暂停，默认快捷键为 `Pause`。
- `Frame Advance`：暂停时前进一帧，默认快捷键为 `V`。
- `Stop`：停止正在播放的序列。
- `Quit Game 退出游戏`：关闭受控游戏。全流程播放中会先停在原生帧边界，再请求退出；回放完成后也可直接点击。启动第 0 帧还未加载 Movie 时同样可用。需要保留录制内容时，先停止并保存 Movie。关闭 Studio 请另用 `File → Exit 关闭 Studio`。
- `Frame`：当前 TAS 输入帧。

关闭 Studio 会同时结束它启动的受控游戏，即使游戏正在暂停或没有响应；需要保留的 Movie 请先保存。普通游戏进程不属于 Studio 的关闭范围。

修改未来帧后形成的编辑回放在末尾原地暂停，下一次播放／逐帧自动补空帧并在同一游戏进程继续，不为此重启游戏。修改已经执行过的输入仍需要明确选择重放。

序列表格右键菜单的「播放到第 N 帧并暂停」只对未来帧可用，从当前进度直接播放，自动同步合法的未来帧编辑，不重启游戏。「恢复到第 N 帧并暂停」只对过去帧可用，重启受控游戏后重放当前草稿到该帧，不要求该帧预先存档。当前帧两项均不可用；执行前会再次核对真实暂停位置。

快捷键只在 Studio 窗口获得焦点时生效。可在 `Settings → Hotkeys` 修改播放和逐帧按键。

输入序列的动作列头显示游戏当前绑定的按键，优先键盘，无键盘绑定时显示其他设备绑定。方向键显示箭头，Enter 显示 ↵；悬停查看动作名和完整键名。列宽随键名自动调整。游戏输入系统尚未就绪时显示 ?，未绑定显示 —；连接后随状态自动刷新，切换会话会清空旧键位。这里只改变显示，Movie 仍记录动作，不受键位习惯影响。

## 从启动第 0 帧播放或录制 v2 Movie

1. 从 Steam 启动游戏，在标题界面的 `选项 → Modding → HollowKnightTAS` 点击 `打开 Studio（重启游戏）`，等待 Studio 显示 `Native frame: 0`。
2. 回放时用 `Movie → Open Movie 打开…` 选择 v2 `.hktas`；录制时先选游戏鼠标模式，再用 `Movie → New full-run Movie 从第 0 帧新建`。
3. 点击 `Frame Advance` 或 `Play`。Movie 的真实输入会操作标题菜单并选择存档；场景加载以及确认保存退出后的保存、淡出过程只影响等待时间，不移动 Movie 输入位置。暂停时可查看当前 Movie 帧和原生帧。
4. 录制完成后停止并通过 `Movie → Save Movie 保存…` 保存。回放结束后核对 `Completed`、输入偏差数和游戏终态。

已验证的假骑士示范在 `fixtures/full-run/false-knight-startup-v2.hktas`。按上述步骤打开即可由序列在标题菜单选择第 4 槽，进入神居假骑士战斗并返回神居；不需要先手动进入存档。该文件有 10892 个 Movie 帧，需使用含 `load-elision-scene-rng-2026-v3` profile 的当前 Mod。游戏加载变慢时，Studio 的原生帧数会增加，Movie 帧位置保持不变。

v2 Movie 不绑定某一个槽位或存档哈希；若存档内容不同，输入仍会执行，但结果可能不同。v2 的协议、动作表及原生加载省帧／随机同步 profile 必须匹配。旧 v2 试验文件若使用旧 profile，需重新录制或明确转换并验证，不能当作已兼容的新 Movie。

## 播放旧版局内 TAS（v1）

1. 从 Steam 启动游戏，在标题的 Modding 设置中手动打开 Studio，等待重新启动并显示启动暂停点。此时可在 `Movie → Open Movie` 预览 v1 `.hktas` 文件。
2. 点击顶部 `Play` 继续初始化。在游戏标题画面选择序列所需的存档槽；进入起点场景后，等待 Studio 显示 `READY` 和 `CONNECTED · IPC v1`。
3. 如果需要恢复已保存的位置，打开 `Timeline`，选择时间线、世界线和节点，点击“恢复所选节点”，等待重放完成。
4. 在 Studio 点击 `Pause`，打开 `Movie Text`，依次点击 `Validate`、`Upload`、`Start Replay`。开始回放后仍处于暂停状态；点击 `Frame Advance` 可执行 Movie 第 0 帧，再次点击逐帧推进，点击 `Play` 则连续播放。
5. 回放结束后查看 Runtime 状态中的 `reason=Completed` 与 `mismatchCount`。回放完成后游戏可能继续运行，需要查看终点时及时点击 `Pause`。

存档显示 `Incompatible` 或 `Upload` 报 `HKTAS220` 时不要强行使用。通常是游戏版本、Mod manifest、画面分辨率/窗口模式、基准存档或序列身份与当前环境不一致，应换用该序列配套的环境和存档。

## 编辑输入

`Input Editor` 每行代表一帧，每列代表一个游戏输入。单击格子可切换输入；按住 `Shift` 选择连续多帧后，可以一次修改整个选区。修改按键或撤销后，选区会保留，便于继续编辑其他列。

播放和逐帧时，默认勾选的 `播放时跟随` 会把当前 Movie 帧滚动到可见区域；整个序列连续滚动，按需生成可见行，不再限制为 500 行。滚轮查看其他帧不会改变跟随勾选状态；取消勾选可持续查看其他位置，`当前帧` 按钮随时可手动定位。全流程 v2 的表格行号按 Movie 帧计算，加载时跳过的原生循环不会推进表格行号；顶部同时显示 Movie 帧和原生帧。

- `Frame` 和 `Count`：选区起始帧和帧数。
- `Undo / Redo`：撤销或重做草稿修改。
- `Copy / Paste`：复制输入帧，或用剪贴板内容替换选区。
- `Insert / Delete`：插入空帧或删除选区。
- `Axes`：设置模拟轴，范围为 `-10000` 到 `10000`。

全流程 v2 表格编辑先改变草稿；当前尚未执行的帧及未来帧，会在下次播放／逐帧前自动同步到游戏。修改过去输入后，使用 `应用并重放到 Frame`，从第 0 帧冷启动重放到目标位置。旧 v1 仍需应用分支。

在按键格子按住鼠标并上下拖动，可连续设置整段帧。输入列和勾选／取消状态由起始格子决定，横向移出该列仍有效；松开后作为一次操作，可撤销。默认行高为 19 像素。

滚到末尾继续向下滚动会按块补充空帧。`默认 FPS` 用于新建录制及之后补充的空帧；已有帧保持原值。选中一帧、多帧或不连续帧，在 `选区 FPS` 输入数值，再点击 `设置帧率`。FPS 支持整数 1–1000，默认 50，随 Movie 保存并在回放时控制实际游戏时间步长。未来帧的 FPS 修改也会在下次播放／逐帧前自动同步；过去帧需要重放。

右键某帧可直接播放到未来帧、重放恢复到过去帧、保存该帧，以及复制、粘贴、插入、删除、应用选区 FPS。帧号表示下一帧输入执行前的边界。未来帧播放保持当前游戏进程；过去帧恢复、应用重放和 Timeline 读档会重启受保护游戏并重放，需要等待。帧存档同时保存对应 Movie，读档会恢复该序列。原始存档基准变化时拒绝恢复，避免从不同起点重放。

全流程 v2 回档期间，游戏保留回档前的静止画面，Studio 帧表格也保持原位置并暂时禁止操作；完成后一起显示目标结果。`播放时跟随` 的勾选状态保持不变：开启时完成后定位目标帧，关闭时保留浏览位置。若无法捕获原游戏画面，会保留原进程并显示错误；已进入恢复后发生错误，则解除显示冻结并显示原因。

表格快捷键：`Ctrl+C/V` 复制和粘贴，`Ctrl+Z/Y` 撤销和重做，`Insert/Delete` 插入和删除。

## 人工录制输入

1. 先暂停游戏。
2. 打开 `Tools → Advanced Authoring`。
3. 点击 `Start Recording`，回到游戏进行操作。
4. 完成后点击 `Stop Recording`。
5. 打开 `Movie Text` 查看、校验并保存生成的序列。

`Advanced Authoring` 也支持单帧指定输入、批量输入、编辑完整局内记录、分支切换和按帧定位。普通编辑优先使用 `Input Editor`。

## 存档和回档

- `Shift+F1` 到 `Shift+F10`：保存到对应快捷槽。
- `F1` 到 `F10`：从对应快捷槽恢复。
- `Timeline → 保存当前帧为节点`：保存当前位置；也可使用表格右键存档。
- 在 Timeline 选择世界线及其节点，选择 F1～F10，点击“将所选节点绑定到快捷键”。绑定不新建节点、不改变游戏位置；已有快捷槽会改为指向所选节点。

快捷槽保存的是存档引用和 TAS 帧位置，不是完整进程内存快照。恢复过程会执行兼容性检查，并通过输入重放回到目标帧。恢复期间等待 `Completed`，不要同时发送其他运行命令。

存档统一在 `Timeline` 管理。节点绑定会记住所选世界线；恢复祖先节点时保留这条世界线的后续序列。旧快捷槽关联保留。

## 导出 MP4

1. 把游戏恢复到序列要求的起点并暂停。
2. 在 `Movie Text` 打开并校验序列。
3. 点击 `导出 MP4`。
4. 首次使用时选择 `ffmpeg.exe`，然后选择一个尚不存在的 `.mp4` 输出文件。
5. 等界面显示导出完成。导出期间不要手动操作游戏。

导出会先上传当前 Movie，再从起点重放并录制。已有输出文件不会被覆盖。

## 常见问题

### 已连接但按钮不可用

等待右上角同时显示 `READY` 和 `CONNECTED`，并确认游戏已经进入可控制小骑士的场景。标题画面和加载过程没有可用的 `HeroController`。

### 在文本框里按 V 没有逐帧

文本输入焦点会优先保留字母输入。点击输入表格或窗口空白处，再按逐帧快捷键。

### 修改了表格但游戏没有变化

全流程 v2 的当前／未来帧修改会在下次播放或逐帧时自动同步；修改过去输入时，点击 `应用并重放到 Frame`。拖动期间实时显示选区和勾选预览，松开后形成一次可撤销的修改。

### F1 没有恢复

先用 `Shift+F1` 保存槽位，并等待存档达到 `Ready`。恢复时 Studio 必须获得焦点。

### Tab 为什么没有快进

当前没有独立的加速播放命令，`Tab` 用于界面焦点导航。

### 时间线与世界线

打开 `Timeline 时间线` 页签。未新建或打开 Movie 时，默认显示“当前空序列（未存档）”，只有 Frame 0 起点；旧时间线仍可从左上方的列表主动切换查看，不会自动加载进当前 Movie。每个新建或打开并预置的全流程序列拥有独立时间线。旧版索引中仍存在的帧存档会自动导入历史列表，旧版快捷槽不会显示为当前空序列的存档。

- 右键帧保存、页面的“保存当前帧为节点”、全流程 Shift+F1…F10 快捷存档都会新增节点。同一帧多次保存不会覆盖历史节点。
- 父节点按实际已执行的输入历史匹配。修改两个存档之间的输入，再重放／步进并存档，会从最后一个仍兼容的存档处分叉。Frame N 表示已执行 [0,N)；尚未执行的未来草稿不会让过去节点分叉。
- 点击叶子或使用世界线下拉框选择世界线，再点击绿色路径上的节点，或从右侧列表选择节点。点击“恢复所选节点”才会操作游戏；单击节点只改变选择。
- 恢复祖先节点时，编辑器和游戏加载所选叶子的序列，所以后续输入来自所选世界线。恢复仍是从第 0 帧重启重放，不是内存快照。请先启动 Studio 的受控游戏；原始存档或运行环境不兼容时拒绝恢复。
- “删除节点及子树”会先显示确认框，移除该节点和全部后代，其他分支不受影响；删除起点会清空所有存档节点并保留 Frame 0。此操作不可撤销，当前游戏和草稿不随删除而改变。

树和序列存储于 `%LOCALAPPDATA%/HollowKnightTAS/studio-frame-saves/timelines.json`，重新打开 Studio 后仍可选择。保存 Movie 文件本身只是导出序列，不创建状态节点。旧 v1 快捷存档继续使用原流程。
