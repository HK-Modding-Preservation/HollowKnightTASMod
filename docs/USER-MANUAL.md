# HollowKnightTAS Studio 操作手册

Studio 用来逐帧播放、编辑和回退《空洞骑士》的 TAS 输入。普通游戏保持原样；需要 TAS 时，在标题的「选项 → Modding → HollowKnightTAS」点击「打开 Studio（重启游戏）」。仍保留这个入口；已接管游戏时不显示启动按钮。单独打开 Studio 且未接管游戏时，顶部提供「启动游戏…」入口。

## 快速开始

1. 等待游戏停在 Native frame 0。
2. 在 Input Editor 打开 `.hktas`，然后 Play 或逐帧。不需要手动 Validate、Format、Upload。
3. 没有打开文件时，直接 Play 或逐帧会新建录制；输入表格会随运行增长。
4. Pause 暂停；Frame Advance 前进一帧；Quit Game 退出受控游戏。
5. Ctrl+S 或「保存序列」导出 `.hktas`，文件位置由保存对话框选择。

游戏加载期间只推进原生循环，不消耗 Movie 输入帧。表格行号是 Movie 帧；Frame N 表示已经执行 [0,N)，下一步将执行第 N 帧。

游戏写入使用受保护影子存档，不自动写回原始存档。Movie 不保证兼容不同的起始存档，请使用该序列对应的基准。

## 编辑输入

Input Editor 每行是一帧。动作列头显示游戏绑定的按键，悬停可看动作名；未初始化显示 ?，未绑定显示 —。

- 第一行：Undo、Redo、Copy、Paste、Insert、Delete。
- 第二行：打开、保存、设置默认帧率、重新计算到选中帧、播放时跟随、MP4。
- 单击按键格切换输入；按住鼠标上下拖动可编辑整段。拖动锁定起始列，松开后形成一次可撤销的修改。
- Shift 选择连续多帧，Ctrl 选择不连续帧。右键保留已有多选区，可复制、粘贴、插入、删除和修改选区帧率。
- 滚到末尾继续向下滚动，会补充空帧。

未来帧的按键和帧率修改会在下一次播放/逐帧前自动同步。修改过去输入后，选择目标行，点击「重新计算到选中帧」；目标可以是过去、现在或未来。

在「设置 → 默认帧率 → 修改…」弹框修改新建/追加空帧的 FPS，已有帧保持原值。选区 FPS 在右键「修改选区帧率…」弹框设置。支持整数 1–1000，初始默认 50；帧率随序列保存。

播放时勾选「播放时跟随」，表格实时跟随。取消勾选可停留在任意浏览位置。滚轮不会改变跟随选项。

## 重算和回档

右键未来帧可「播放到该帧并暂停」，一般在原进程继续；右键过去帧可「恢复到该帧并暂停」。不要求先在该帧存档。中途切换文件后，需要重启重放来应用新序列。

回档采用受保护重启与重放。期间游戏保留静止画面，表格、选区和滚动位置保持静止并禁止编辑，顶部显示不带具体帧数的等待进度条。完成后一起显示目标结果；跟随选项保持不变。失败会解除冻结并报告原因。

## 时间线与分支

时间线标签始终可见。

- 「保存当前帧为节点」、右键存档、Shift+F1…F10 新增手动存档点，不覆盖旧节点。
- 每条分支额外保存「最远进度」叶子：是该分支实际运行到的最远帧，不是文件末尾。叶子同时保存完整序列，包括尚未运行的后续输入。
- 暂停、切换文件/分支、关闭 Studio 时自动保存分支。回到较早位置不会降低原分支的最远帧；修改过去输入会形成新分支。
- 点击叶子立即加载该分支的完整序列，不需要「应用分支」。选择路径上的存档点后，点击「恢复所选节点」才会改变游戏位置。
- 恢复祖先存档点，保留所选叶子的后续序列。
- 选择节点后可绑定 F1…F10；F1…F10 恢复，Shift+F1…F10 保存。绑定本身不新建节点。
- 删除节点及子树需要确认；删除起点会清空该树的节点并保留起点。请谨慎操作。

时间线存放于 `%LOCALAPPDATA%/HollowKnightTAS/studio-frame-saves/timelines.json`。重新打开 Studio 默认显示空序列，旧树从 Timeline 左上列表选择。自动保存到 Timeline **不等于覆盖导出的 `.hktas` 文件**。

正常关闭 Studio 会先保存当前分支，再退出它持有的受控游戏；保存失败会保持窗口并提示。强制结束进程或断电不保证保存最后一次尚未落盘的编辑。

## 中途打开另一个文件

在 Input Editor 打开文件时，先校验，再暂停并保存原分支，然后替换草稿。校验失败不会覆盖当前序列。切换成功后，Play 从新序列起点开始；也可以选中一行后重算到那里，或在 Timeline 恢复已有节点。旧录制同步不会覆盖刚打开的序列。

## 页面和快捷键

界面只保留四页：输入编辑器、时间线、操作手册、设置。英文界面对应 Input Editor、Timeline、Manual、Setting；顶部菜单栏已移除。输入表格不再显示 Channels / Samples 诊断列。

- Pause：播放/暂停；V：逐帧。可在「设置 → 快捷键」修改。
- Ctrl+O / Ctrl+S：打开/导出序列。
- Ctrl+C/V、Ctrl+Z/Y、Insert/Delete：表格编辑。
- F1…F10：回档；Shift+F1…F10：存档。

快捷键仅在 Studio 获得焦点时生效，输入文本时优先输入文字。Tab 用于界面导航，目前没有独立快进命令。

「设置」集中管理界面语言、默认帧率、游戏鼠标和快捷键。语言支持中文或 English，立即切换并保存在 `%LOCALAPPDATA%/HollowKnightTAS/studio-language.txt`，下次启动沿用；初次默认为中文。界面标签、菜单、弹框正文和常用状态随语言切换，实际文件名、按键名及底层诊断标识保持原样。Windows 原生文件选择框及消息框的系统按钮遵循 Windows 语言。

默认帧率只影响新建及追加帧。游戏鼠标模式用于新序列，已开始的序列保持它记录的模式；此设置不影响 Studio 自身鼠标。快捷键沿用原配置和保存方式。

## 导出 MP4 与旧版工具

MP4 入口已移到 Input Editor，导出状态也在该页显示；取消导出按钮也在该页。现有导出器面向旧版局内 v1 序列，本轮没有新增全流程 v2 视频编码能力。

使用兼容的旧版局内会话时，暂停并恢复到序列起点，打开文件后点击「导出 MP4」，选择 ffmpeg.exe 和一个不存在的新 `.mp4` 文件。导出会重放并录制，期间不要手动操作游戏，不覆盖已有视频。

运行状态、Advanced Authoring、事件日志、差异、External Control 等开发页面已从日常界面移除；常规编辑使用输入编辑器。底层协议和自动化服务保持原有接口。
