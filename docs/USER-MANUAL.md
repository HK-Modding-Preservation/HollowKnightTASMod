# 玩家安装与使用

HollowKnightTAS Studio 用来录制、编辑和回放《空洞骑士》的逐帧输入。界面包含输入编辑器、时间线、操作手册和设置四页，支持中文与 English。

## 安装与启动

需要 Windows x64、《空洞骑士》和已安装的 Modding API。使用完整的 HollowKnightTAS 发布包，保留配套工具的目录结构。Studio 发布包自带 .NET 运行时；导出视频另需 FFmpeg。

1. 保存编辑并关闭游戏和 Studio。
2. 将包解压到游戏的 `hollow_knight_Data/Managed/Mods/HollowKnightTAS`。若压缩包已有顶层 `HollowKnightTAS` 文件夹，则解压到 `Mods`。避免形成双层同名目录。
3. 确认该目录直接包含 `HollowKnightTAS.dll`、`HollowKnightTAS.Core.dll`、`companion.manifest.json` 和 `Companion/win-x64/HollowKnightTAS.Companion.exe`。更新时使用同一发布包中的完整配套文件。
4. 启动游戏，在标题画面的「选项 → Modding → HollowKnightTAS」选择「打开 Studio（重启游戏）」。等待受控游戏停在启动第 0 帧。

也可以直接运行上述 Studio 程序，使用「启动游戏…」选择 `hollow_knight.exe`。普通启动游戏时，TAS 控制、录制、外部接口和碰撞箱显示保持未激活。

其他 Mod 可以一起启用，兼容性由使用者确认。回放会核对实际运行环境，包括游戏及 Mod 身份、画面等设置；环境不匹配时应使用匹配环境重新运行。

## 开始录制或回放

在输入编辑器打开 `.hktaspack` 序列包，然后播放或步进。未打开序列时，播放或步进会开始新录制。录制包含菜单和游戏操作；游戏加载期间推进原生循环，但不消耗 Movie 输入帧。

顶部「播放/暂停」切换运行状态，「步进」推进一帧；继续播放快捷键 P 只在暂停时继续。Frame N 表示输入区间 `[0,N)` 已执行，下一步执行第 N 行。Native frame 是原生循环计数，不能直接当作表格行号。

默认快捷键：

| 操作 | 按键 |
| --- | --- |
| 播放/暂停 | Pause |
| 继续播放 | P |
| 步进，按住连续步进 | V |
| 打开 / 保存序列 | Ctrl+O / Ctrl+S |
| 复制 / 粘贴 | Ctrl+C / Ctrl+V |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 插入 / 删除帧 | Insert / Delete |
| 恢复快捷槽 | F1–F10 |
| 保存快捷槽 | Shift+F1–F10 |

在设置页可以修改控制快捷键。启用「全局热键」后，游戏或其他窗口获得焦点时，播放、暂停、继续、步进和快捷槽仍可使用；文件及表格编辑快捷键只在 Studio 内生效。注册冲突会显示在设置页。文本框内优先输入文字。

## 编辑输入

每行对应一帧，动作列头显示游戏绑定的按键，悬停可查看动作名。单击按键格切换输入，按住鼠标上下拖动可编辑同一列的一段输入。Shift 选择连续帧，Ctrl 选择不连续帧；右键菜单可复制、粘贴、插入、删除及修改选区帧率。滚到末尾后继续向下滚动可追加空帧。

未来输入在下一次播放或步进前自动同步。修改已经执行过的输入后，选中目标行并点击「重新计算到选中帧」，让游戏按修改后的序列恢复到目标。勾选「播放时跟随」后，表格随实际执行位置滚动；取消后可停留在任意浏览位置。

默认帧率为 50，允许整数 1–1000。设置页的默认帧率只影响新建和追加帧；已有帧通过右键「修改选区帧率…」修改。游戏鼠标开关用于新序列，已开始的序列沿用记录的鼠标模式。

## 保存序列和初始存档

Ctrl+S 或「保存序列」首次选择文件路径，之后覆盖当前文件；「另存为」保存到新路径。新建序列使用 `.hktaspack`，包含完整输入以及启动第 0 帧固定的四槽初始存档快照，包括空槽和槽位关联的 Mod 文件。分享序列包即可携带这些初始条件。

保存、另存为及自动保存保留同一份初始快照，不采集录制后的游戏进度。播放、重播、回档及视频导出从包内快照建立独立影子存档，受控游戏中的存取档只改变影子副本。存档绑定不能替代运行环境兼容性校验。

`.hktas` 文本序列显示「未绑定初始存档」，依赖本机起始存档；保存时仍使用该格式。包损坏或初始存档缺失时会拒绝加载。

默认序列目录为 Windows 文档目录下的 `HollowKnightTAS/Sequences`。自动保存按现实时间每 300 秒（5 分钟）检查一次，将有变化的完整草稿写入该目录的 `Autosave` 子目录，不覆盖手动保存的文件，也不推进游戏。设置页可修改目录和间隔，0 表示关闭，最大 86400 秒；已有设置继续生效。

## 时间线与回档

时间线保存不同输入分支及恢复节点。分支叶子记录实际运行到的最远帧，同时保留完整未来输入。点击叶子加载该分支，选择节点并执行「恢复所选节点」才改变游戏位置。恢复祖先节点后仍保留所选分支的后续输入。

「保存当前帧为节点」、表格右键保存及 Shift+F1–F10 记录恢复目标，不播放或回档到目标。运行中保存会先暂停。未来帧或修改后尚未验证的目标标记为「未验证存档」，不计入实际最远进度。F1–F10 执行恢复；时间线中可将现有节点绑定到快捷槽。

右键未来帧可播放到该帧并暂停；过去帧可恢复到该帧并暂停，不必事先创建节点。回档通过受保护重启和输入重放完成，需要等待。期间游戏画面、表格与选区保持静止，禁止编辑，进度条按已重放帧数与目标帧数更新；完成后显示目标结果，失败则解除冻结并提示原因。

暂停、切换文件或分支、正常关闭 Studio 时会保存本机时间线。时间线位于 `%LOCALAPPDATA%/HollowKnightTAS/studio-frame-saves/timelines.json`，与序列文件和 `Autosave` 副本独立。重新打开 Studio 后，可从时间线列表选择已有记录。删除节点及子树前会要求确认。

中途打开文件会先校验文件，再暂停并保存原分支；加载失败保留当前序列。成功切换后，播放从新序列起点开始，也可重算到选中行。正常关闭 Studio 会先保存分支再退出其持有的受控游戏；保存失败时窗口保留并提示。强制结束进程可能丢失尚未落盘的编辑。

## 导出 MP4

准备 `ffmpeg.exe` 和一个尚不存在的 `.mp4` 输出路径。当前视频导出要求序列固定为 50 fps。

- 输入编辑器的 MP4 按钮导出当前完整序列，包括未来草稿输入。
- 时间线中设置起点和终点，导出同一祖先路径上的区间 `(起点帧,终点帧]`。反向选择自动排序，兄弟分支之间不能直接导出。

导出会自动恢复并回放；准备阶段不录入视频，正式采集期间的加载画面会录入，所以视频帧数可能多于 Movie 输入帧数。暂停后可继续同一次采集，取消准备或采集不发布最终 MP4。以导出状态完成为准，不以请求返回或临时文件出现为准。

## 设置与故障处理

设置页可以选择语言、帧率、鼠标模式、序列保存目录、自动保存间隔、快捷键和碰撞箱显示。碰撞箱默认关闭，只显示轮廓，不改变游戏碰撞判定。

- Studio 未连接：确认通过 TAS 启动入口启动，等待 Runtime 就绪；普通游戏会话不提供 TAS 控制。
- 配套文件校验失败：重新安装完整的同一发布包，保留目录结构。
- 序列环境不匹配：恢复录制时的游戏、Mod 和画面设置。不要通过修改环境指纹跳过校验。
- 回档或导出失败：保留错误信息并检查当前操作状态，避免重复提交。
- 需要日志时查看游戏用户目录中的 `ModLog.txt` 和 `Player.log`，Windows 通常位于 `%USERPROFILE%/AppData/LocalLow/Team Cherry/Hollow Knight`。
