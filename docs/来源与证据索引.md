## 访问与变动说明

- **已重新访问并确认关键版本信息**：S1 的发布页在 2026-07-27 显示 “ModdingAPI v77 for Hollow Knight 1.5.78.11833”。
- **已重新访问并确认历史路线边界**：S5 的 README 仍说明其在 Linux + libTAS 侧运行，并覆盖 `Assembly-CSharp.dll`；因此它不能被写成普通 HK Mod 的直接模板。
- **已重新访问并确认时间模型依据**：S6/S8 仍阐明 visual frame、fixed timestep 与 `timeScale` 的相关语义。文档没有据此断言 Hollow Knight 的精确 Unity 版本或调用顺序。
- **已读取 CelesteTAS 当前官方仓库和源码**：S15-S17 证明其产品确实采用 Mod + Studio + 共享通信层，并支持按设置随游戏启动 Studio；本项目只借鉴分层，不复制具体共享内存或下载策略。
- **已核对 Windows 外部能力边界**：S18 的 API 目标是捕获/查询进程诊断数据，公开函数集合没有“恢复整个目标进程”操作；因此 T13 仍须把即时 savestate 作为实验 capability，而不是既成能力。
- **已核对 Mod 启动外部程序的 API 边界**：S19 支持固定可执行文件的直接启动方案；安全性还必须由签名 manifest、固定路径、当前用户 IPC ACL 和不可由 movie 控制的参数共同保证。
- **已读取 CelesteTAS/Speedrun Tool 的实际 savestate 路径**：S20-S24 显示其核心是同进程 `Level`/`SaveData` 托管图克隆，加上 RNG、输入、静态状态、音频、Mod 等显式恢复 action 和不安全状态拒绝；不是跨启动完整进程快照。
- **已核对 Unity 托管/native 与序列化边界**：S25-S26 支持“不应通用持久化全部 Unity 对象图”的约束；T14 因此采用安全 room-entry、白名单 DTO adapter、短尾重放和 T09 回退。
- **已核对外部 AI 协议与本地安全边界**：S27-S30 支持 T15 用 resources/tools 表达语义状态与 typed control，v1 选择 stdio AgentBridge、Companion 授权、最小 scopes、短期租约和完整审计；不开放本地 HTTP 或把 MCP session 当作认证。
- 其余来源的 URL 已从上一轮完整产物保留；未来实施时应按目标游戏构建再次检查 commit、发布物和文档版本。
