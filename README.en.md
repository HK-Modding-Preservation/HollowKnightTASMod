# HollowKnightTASMod

[中文](README.md)

A tool-assisted speedrun toolkit for Hollow Knight, with an in-game Runtime, a Windows Studio input editor, and local control interfaces for AI clients and scripts.

Studio supports recording and replay from startup, frame-by-frame input editing, timeline branches and replay-based restore, sequence packages with bound starting saves, and MP4 export. Normal game launches retain ordinary play; open Studio from the title menu to enter TAS mode.

The complete release includes FFmpeg; exporting an MP4 only requires choosing an output file.
